Steps to add this in Articulate Rise:
  1. Add a new block where the component should appear and open the Block library.
  2. Select </> Code.
  3. Choose Add code, then paste the code copied above into the code editor.
  4. Save the code block, then preview the lesson to confirm it renders and responds to clicks/keyboard before publishing.
