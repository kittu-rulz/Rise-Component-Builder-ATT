<iframe src="https://rise-builder.cloud.app/preview/accordion-abc123xyz" width="100%" height="450px" style="border:none;"></iframe>
Suggested steps in Articulate Rise (not independently verified — see compatibility note above):
  1. Add a new block where the component should appear and open the Block library.
  2. Select </> Code.
  3. Choose Add code, then paste the complete iframe code copied above into the code editor.
  4. Save the code block, then preview the lesson and adjust its height if needed.
  5. Confirm the block actually renders and responds to clicks/keyboard in Rise's own preview before publishing — do not assume success from these steps alone.

<style>

</style>

<div class="rise-block-wrapper">

Packages this component as a real, standalone ZIP: index.html at the root, plus every uploaded image or audio file it actually uses under assets/. Unlike the single-HTML option, uploaded audio, video, and large images travel as real files instead of being blocked or embedded as (potentially very large) inline data. Extract the ZIP and host index.html plus its assets/ folder wherever your course's other external content lives, or open index.html directly to verify it first — see the compatibility note above for what is and isn't confirmed about using this inside Rise itself.
